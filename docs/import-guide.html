🚀 ইম্পোর্ট করার সহজ ধাপসমূহ

  1. অ্যাডমিন প্যানেলে লগইন করে সাইডবার থেকে ক্যাটালগ → প্রোডাক্ট ম্যানেজমেন্ট-এ যান।
  2. উপরে ডানপাশের "CSV ইম্পোর্ট করুন" বাটনে ক্লিক করে /admin/products/import পেজে যান।
  3. আপনার স্ক্যাপারের তৈরি .csv ফাইলটি নির্বাচন করুন (UTF-8 বাংলা ইউনিকোড সাপোর্ট নিশ্চিত করে)।
  4. ফাইল সিলেক্ট করতেই প্রথম ১০টি সারির লাইভ প্রিভিউ (Preview) ও মোট বৈধ সারির গণনা দেখতে পাবেন।
  5. "ইম্পোর্ট শুরু করুন" বাটনে চাপ দিলে সিস্টেমে রিয়েল-টাইম ইম্পোর্ট প্রসেসিং শুরু হবে এবং শেষ হলে পূর্ণাঙ্গ পরিসংখ্যান প্রদর্শিত হবে।

📊 CSV কলাম ম্যাপ ফিল্ড নির্দেশিকা

CSV কলাম ডাটাবেস ম্যাপিং বিবরণ ও ফিল্টার নিয়ম
name Product Name প্রোডাক্টের নাম (আবশ্যক ফিল্ড)
author Author Name লেখকের নাম (বিদ্যমান থাকলে রিইউজ, না থাকলে অটো ক্রিয়েট)
publisher Publisher Name প্রকাশনীর নাম (স্বয়ংক্রিয় রিইউজ বা তৈরি)
category Category Name ক্যাটাগরির নাম (স্বয়ংক্রিয় রিইউজ বা তৈরি)
regular_price Regular Price মূল দাম (সংখ্যা)
sale_price Sale Price বিক্রয় মূল্য (সংখ্যা)
discount Discount % ছাড়ের শতাংশ (স্বয়ংক্রিয় গণনাকৃত বা সরাসরি প্রদত্ত)
id Source Product ID এক্সটার্নাল সোর্স প্রোডাক্ট আইডি (ডুপ্লিকেট রোধার অন্যতম প্রাইমারি ইন্ডেক্স)
url Source URL মূল সোর্স ইউআরএল (ডুপ্লিকেট রোধার সেকেন্ডারি ইন্ডেক্স)
